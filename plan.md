# Prompt: Build a Modern React Website for "Yash Tent & Light Decoration"

Act as a Senior React Developer, UI/UX Designer, and Frontend Architect.

Build a modern, responsive, SEO-friendly, production-ready website for **Yash Tent & Light Decoration**, a company that provides tent decoration, wedding decoration, lighting, catering setup, stage decoration, flower decoration, and event management services.

* React.js

* Framer Motion
* React Icons
* Swiper.js
* Axios
* React Hook Form
